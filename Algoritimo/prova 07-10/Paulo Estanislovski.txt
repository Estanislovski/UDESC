Exercicio 1:
Julgue as afirmativas abaixo com V – Verdadeiro e F – Falso.
(V) - Sendo a uma variável inteira, a seguinte instrução é válida: scanf("%i", &a);
(V) - A seguinte instrução char f ; declara uma variável do tipo caractere unitário
com nome f.
(F) - A instrução printf(‘Digite seu nome \n’); está errada.
(V) - O default no swith-case serve para criar um bloco de código que será
executado automaticamente caso o valor avaliado pela expressão do switch não
corresponda a nenhum dos case definidos.

Exercicio 2:

#include <stdio.h>
#include <stdlib.h>

int main() {
    float metros;

    printf("Digite um valor em metros (1.00, não utilize virgula): ");
    scanf("%f", &metros);

    printf("%.2fm corresponde a %.0fcm!", metros, metros * 100);
    return 0;
}

#include <stdio.h>
#include <stdlib.h>

int main() {
    int quantidade;

    printf("Informe a quantidade de maçãs compradas: ");
    scanf("%i", &quantidade);

    if (quantidade <= 0){
        printf("Quantidade comprada não pode ser menor que 1.\n");
        printf("Informe um valor valido!");
    } else if (quantidade < 12){
        printf("Valor total da compra R$%.2f!\n", quantidade * 0.3);
        printf("Cada maçã custa R$0,30!");
    } else{
         printf("Valor total da compra R$%.2f!\n", quantidade * 0.25);
        printf("Cada maçã custa R$0,25!");       
    }
    return 0;
}
